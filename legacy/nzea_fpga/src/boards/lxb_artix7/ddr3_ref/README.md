# ddr3_ref — MicroPhase A7-Lite DDR3 reference (21_ddr3_test)

Reference only. Copied from the MicroPhase A7-Lite `21_ddr3_test` Vivado
example (`Copyright (c) 2022 by MicroPhase Technologies Inc.`); kept here as
the authoritative source for DDR3 integration on the lxb_artix7 board.

Contents:

- `mig_ddr3.xdc` — DDR3 pin/I/O constraints. `nzea_fpga/scripts/vivado-project.nu`
  renames its `ddr3_*` nets to the top-level `DDR3_*` ports to derive the pin XDC.
- `srcs/sources_1/ip/mig_ddr3/` — MIG 7-series IP. The build reads `mig_b.prj`
  (via `vivado-project.py --mig-prj`): MT41K256M16XX-107, 16-bit DQ, 400 MHz
  memclk, 4:1 PHY → 128-bit native app interface at 100 MHz ui_clk, NATIVE,
  15-row/10-col/3-bank. `mig_a.prj` / `mig_ddr3.xci` are kept as reference.
- `srcs/sources_1/ip/clock/` — clk_wiz for the example's own clocking.
  Reference only; nzea builds its MMCM from `ip_clk_wiz.tcl` (`Mmcm50to200`).
- `srcs/sources_1/ip/ila_top/` — the example's ILA IP. Reference only; nzea
  generates its own ILA from `ila_config.json` when `--debugIla` is set.
- `srcs/sources_1/new/` — example design RTL. `ddr3_ctrl` wraps the MIG and
  exposes a wr/rd-separated flow-control interface. Timing reference only;
  `Ddr3Adapter` targets the raw MIG `app_*` interface instead. The
  `app_wdf_end`/`app_wdf_wren` semantics shown in `ddr3_wr_ctrl.v` are what the
  adapter's write path mirrors (that file is the one cited by the bring-up).

Not vendored, and why:

- The Micron DDR3 behavioural model (`ddr3_model.sv`, `wiredly.v`, ...) is
  **generated by Vivado** from the IP configuration (`generate_target all`), so
  no copy is kept here — a committed copy could silently drift from the actual
  IP. The xsim cosim (`just vivado-sim`) uses the generated copy under
  `build/.../vivado/nzea_fpga.gen/.../example_design/sim/`.
- The vendor simulation testbench (`sim_tb_top.v`) is likewise regenerated per
  build. The cosim reuses it verbatim apart from the name of the instantiated
  top module; see `nzea_fpga/src/boards/lxb_artix7/sim/nzea_ddr3_sim_top.v`.

Integration: DDR3 is a fabric slave on the tile's external-memory bus via
`Ddr3Adapter` (32-bit LiteBus ⇄ 128-bit MIG app). See
`goal/ddr3-debug-postmortem.md` for the bring-up history and
`goal/roadmap.md` for the remaining tooling gaps.
